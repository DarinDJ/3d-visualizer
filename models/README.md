# Sample models

| File | Source | Notes |
|------|--------|-------|
| `teapot.obj` | Utah teapot (Martin Newell, 1975), copy from [alecjacobson/common-3d-test-models](https://github.com/alecjacobson/common-3d-test-models) | 3,644 vertices, 6,320 triangles, no normals in the file (the loader computes them) |
| `bunny.obj` | Stanford Bunny, [Stanford Computer Graphics Laboratory](http://graphics.stanford.edu/data/3Dscanrep/), copy from the same repository | 35,947 vertices, 69,451 triangles |
| `cube.obj`, `sphere.obj`, `torus.obj` | generated by `make_models.py` | carry analytic per-vertex normals (`vn`), so they also exercise the `v//vn` face syntax |

The Stanford Bunny is provided by Stanford for non-commercial research and educational use.
Regenerate the procedural models with:

```
python models/make_models.py
```
